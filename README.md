# 轻压

在浏览器本地压缩视频的小网页。视频不会上传到任何服务器，全部在用户自己的浏览器里处理。

## 功能

- 上传或拖入视频（MP4、MOV、WebM 等）
- 可选清晰度（原始 / 1080p / 720p / 480p）、压缩力度（画质优先 / 均衡 / 体积优先）、帧率（最高 30 帧 / 保持原帧率）
- 压缩前显示预计体积，压缩中显示进度和剩余时间，可随时取消
- 压缩完成后可预览，再下载 MP4

## 技术说明

- 单文件页面：`index.html`，无需构建
- 使用 [Mediabunny](https://mediabunny.dev) 1.60.0（从 jsDelivr 加载），基于浏览器的 WebCodecs 硬件编解码
- 推荐使用电脑上最新版的 Chrome 或 Edge

## 本地运行

需要通过 http 打开（不能双击用 `file://` 打开）：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
